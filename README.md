# ◓ 포켓몬 파티 패널

**YariPoké 봇용 RisuAI 플러그인**

보유 포켓몬의 타입, 특성, 도구, 기술 배치를 한눈에 확인하고 바로 수정할 수 있는 패널입니다.
채팅을 거슬러 올라가며 기술을 찾을 필요가 없습니다.

- 최신 버전: **1.0.0**
- 다운로드: [`pokedex-panel.js`](https://raw.githubusercontent.com/sat7312/pokedex-party-panel/main/pokedex-panel.js) (링크에서 우클릭 → 다른 이름으로 저장)
- 변경 내역: [CHANGELOG.md](CHANGELOG.md)

## 주요 기능

| 기능 | 내용 |
|---|---|
| 몬스터볼 버튼 | YariPoké 채팅에서만 표시, 드래그로 위치 이동 |
| 파티·박스 관리 | 목록, 상세 정보, 편집, 파티↔박스 이동 |
| 내장 도감 | 타입, 종족값, 특성, 기술 정보, 상성, 진화, 리전폼 |
| 기술 배치 | 배울 수 있는 기술 목록에서 눌러서 지정 |
| 봇 자동 연동 | 파티 태그·보관함 동기화, 진화 인식 |
| 특성 자동 부여 | 미지정 시 일반 특성 중 무작위 지정 |
| 채팅 기록에서 찾기 | 보조모델이 기존 채팅에서 기술·도구·특성 추출 |
| 봇에게 알려 주기 | 응답마다 보유 포켓몬 정보를 봇에게 전달 |

### 몬스터볼 버튼
- YariPoké 채팅에 들어가면 화면에 몬스터볼 버튼이 나타납니다. 홈 화면이나 다른 봇 채팅에서는 숨겨집니다.
- 누르면 패널이 열리고, 드래그하면 원하는 위치로 옮길 수 있습니다. 위치는 화면 비율로 저장됩니다.

### 파티·박스 패널
- 파티(최대 6마리)와 박스 탭으로 나뉘며, 목록에는 스프라이트, 이름, 타입, 레벨이 표시됩니다.
- 상세 화면에서 특성, 지닌 도구, 기술 배치, 종족값, 받는 피해 배율, 메모를 확인할 수 있습니다.
- 편집 화면에서 레벨, 모습(폼), 특성, 도구, 기술, 메모를 직접 수정할 수 있습니다.

### 내장 도감
- 포켓몬 1,351종(리전폼·메가진화 포함), 기술 901개, 특성 309개의 한국어 데이터가 들어 있습니다.
- 타입, 종족값, 특성 후보, 기술의 타입·분류·위력·명중·PP는 도감 값이 자동으로 적용됩니다.
- 리전폼은 이름의 "알로라", "가라르", "히스이", "팔데아"로 알아보며, 편집 화면의 **모습** 항목에서 직접 고를 수도 있습니다.

### 기술 배치
- 상세 화면에 그 포켓몬이 배울 수 있는 기술이 레벨업 / 기술머신 / 알 기술 / 가르침으로 표시됩니다.
- 기술을 누르면 빈 슬롯에 들어가고, 슬롯을 먼저 누르면 그 자리가 교체됩니다.
- 스칼렛·바이올렛(DLC 포함) 기준이며, 해당 작품에 없는 포켓몬은 가장 최근 본가 게임 기준입니다.

### 봇과 자동 연동
- 봇 응답의 파티 상태 태그와 포켓몬 보관함을 읽어 파티와 박스를 맞춥니다.
- 진화를 인식하여 기술·도구·메모를 그대로 이어받습니다. 특성은 같은 칸을 이어받고, 리전폼은 유지됩니다.
- 레벨은 올라갈 때만 반영되며, 사용자가 만든 데이터는 지우지 않습니다.
- 목록 위의 스위치로 끌 수 있고, **지금 동기화** 버튼으로 수동 실행할 수 있습니다.

### 특성 자동 부여
- 특성이 비어 있으면 그 포켓몬의 일반 특성 중 하나를 무작위로 정합니다(숨겨진 특성 제외).
- 채팅 기록에서 실제 특성을 찾으면 그 값으로 바뀝니다. 직접 고른 특성은 변경하지 않습니다.

### 채팅 기록에서 찾기
- 보조모델이 최근 채팅(최대 4만 자)을 읽고 기술, 도구, 특성을 찾아 빈칸에 채웁니다.

### 봇에게 알려 주기
응답을 만들 때마다 아래와 같은 정보를 봇에게 전달합니다. 채팅 기록에는 남지 않습니다.

```
[보유 포켓몬 정보]
파티:
- 한카리아스 Lv.84 (드래곤/땅) | 특성 까칠한피부 | 도구 기합의띠 | 기술 역린, 지진, 스톤에지, 칼춤
보관함: 수레기 Lv.18
```

## 설치 방법

1. [`pokedex-panel.js`](https://raw.githubusercontent.com/sat7312/pokedex-party-panel/main/pokedex-panel.js)를 내려받습니다.
2. RisuAI 설정 → **플러그인** → **플러그인 가져오기**에서 받은 파일을 선택합니다.
3. 처음 실행할 때 나타나는 권한 확인 창을 허용합니다.
4. YariPoké 채팅을 열고 몬스터볼 버튼을 누릅니다.

업데이트는 RisuAI 플러그인 설정의 업데이트 확인으로 받을 수 있습니다. 저장된 데이터는 유지됩니다.

## 보조모델

**채팅 기록에서 찾기**와 도감에 없는 포켓몬·기술의 **✨ 빈칸 채우기**에만 보조모델을 사용합니다.
나머지 기능은 보조모델 없이 동작합니다. 기록에서 찾기는 토큰 사용량이 적지 않으므로 저렴한 모델을 권장합니다.

## 참고 사항

- PocketRisu 환경을 기준으로 제작했습니다. 원본 RisuAI(웹)에서는 동작이 다를 수 있습니다.
- 봇의 업데이트로 태그나 보관함 형식이 바뀌면 자동 동기화가 멈출 수 있습니다.
- 파일 용량(약 550KB)의 대부분은 도감·기술 습득·진화·폼 데이터입니다.
- 버그 제보와 건의는 [Issues](https://github.com/sat7312/pokedex-party-panel/issues)에 남겨 주시기 바랍니다.
